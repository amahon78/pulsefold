# Non Goals

PulseFold is deliberately not trying to solve everything.

## Not V0/V1

- full Datadog replacement
- proprietary telemetry database
- full text log search UI
- APM dashboard suite
- RUM
- session replay
- synthetic browser monitoring
- automatic incident remediation
- autonomous production shell
- Kubernetes operator
- billing platform
- enterprise RBAC
- multi tenant SaaS control plane
- custom foundation model
- reinforcement learning system
- every notification provider
- every cloud specific integration

## Not V0

- production forwarding gateway or fail-open forwarding claim
- active compaction, filtering, sampling or payload externalisation
- metrics or traces beyond transport accounting
- incident engine, correlation state or notification routing
- Slack or other notification adapter
- built-in AI investigator, agent invocation or model call
- evidence-content archive, reconstruction UI or retention-store implementation
- generic customer dollar-saving claim

## Why

Each item expands the trust surface and maintenance burden before the core thesis has been proven.

PulseFold earns the right to expand only after:
- safe telemetry optimisation works
- proactive incident handling is useful
- evaluations show agent investigation adds value
