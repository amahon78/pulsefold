# PulseFold Benchmarks

This directory will hold benchmark definitions, runners and public results.

Planned benchmark groups:

- telemetry reduction
- template quality
- information preservation
- throughput and latency
- detector accuracy
- incident correlation
- model investigation
- prompt injection
- redaction

Benchmark results must state:
- dataset
- version
- machine/runtime
- PulseFold version
- configuration
- scoring method
